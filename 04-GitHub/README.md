
# Evolução do Perfil no GitHub

## 1. Objetivo

Desenvolver e aprimorar minha presença profissional no GitHub, organizando meus projetos acadêmicos e pessoais, documentando meus conhecimentos e demonstrando minha evolução na área de Engenharia de Software.

## 2. Perfil antes das melhorias

Inicialmente, meu perfil apresentava uma estrutura simples, com poucas informações profissionais e repositórios que ainda precisavam de organização e documentação.

![GitHub Antes](imagens/github-antes.jpeg)

## 3. Melhorias realizadas

Durante o semestre, foram realizadas as seguintes melhorias:

- Personalização do README do perfil.
- Atualização da apresentação profissional.
- Organização dos repositórios.
- Criação de descrições para os projetos.
- Padronização dos arquivos README.
- Inclusão das tecnologias utilizadas nos projetos.

## 4. Perfil após as melhorias

Após as atualizações, o perfil passou a apresentar uma estrutura mais organizada, facilitando a visualização dos meus conhecimentos e projetos.

![GitHub Depois](imagens/github-depois.jpeg)

## 5. Organização dos repositórios

Os repositórios foram organizados com nomes claros, descrições e documentação explicativa.

![Repositórios](imagens/repositorios.png)

## 6. Personalização do README

Foi desenvolvido um README de perfil contendo informações sobre minha formação acadêmica, experiências, tecnologias em aprendizado e objetivos profissionais.

![README do Perfil](imagens/readme-perfil.png)

## 7. Reflexão pessoal

A organização do GitHub contribuiu para melhorar minha apresentação profissional e compreender a importância da documentação no desenvolvimento de software.

Além de funcionar como um ambiente para armazenar projetos, o GitHub passou a representar minha evolução acadêmica e técnica ao longo do semestre.
